# app-5 — переключение тем в рантайме

Playground рантайм-слоя `@feugene/unocss-preset-granular/runtime`.

## Для чего

Показать, как приложение переключает темы **без перегенерации CSS**: токены
всех тем уже лежат в стилях, каждая под своим селектором, и переключение — это
одна операция над `<html>`.

Главная мысль: селекторы тем выбирает **провайдер**, а нужны они **браузеру**.
Без канала между сборкой и рантаймом приложение вынуждено дублировать их
руками — и молча разъезжается с провайдером, потому что несовпавший селектор
не даёт ни ошибки, ни предупреждения: просто ничего не переключается. Канал —
манифест тем.

## Что проверяет

- `granularThemesPlugin(granularOptions)` в `vite.config.ts` отдаёт
  `virtual:granular-themes` — имена тем, их селекторы и способ активации.
  Манифест строится из **той же** резолюции, из которой пресет эмитит CSS
  (тот же объект опций), поэтому разъехаться они не могут.
- `createThemeController(manifest)` в `src/theme.ts` — контроллер: `list()`,
  `get()`, `set()`, `cycle()`, `subscribe()`. Создаётся до монтирования Vue,
  чтобы первый кадр рисовался уже в нужной теме.
- Активация выводится из селектора провайдера автоматически. Здесь
  `XTokenized` объявляет `dark` под `.dark, [data-theme="dark"]`, и манифест
  отдаёт `{ type: 'attribute', name: 'data-theme', value: 'dark' }` — атрибут
  предпочитается классу, он взаимоисключающий по природе.
- Выбор сохраняется в `localStorage`; без сохранённого выбора берётся
  системная схема (`prefers-color-scheme`).
- В CSS присутствуют **оба** блока токенов — это и есть предпосылка
  переключения без пересборки.

## Запуск

```bash
yarn workspace @feugene/simple-package build
yarn workspace @feugene/granular-app-5 dev
```

Кнопки в шапке переключают тему; `XTokenized` красится токеном
`--x-tokenized` (light → красный, dark → жёлтый). Перезагрузка страницы
сохраняет выбор.

## Проверка

```bash
yarn workspace @feugene/granular-app-5 build
yarn workspace @feugene/granular-app-5 verify
```

Ожидания — в [`expected-css.mjs`](./expected-css.mjs). Ключевая из них —
наличие в CSS селектора `[data-theme=dark]`, то есть ровно того, который
манифест обещает рантайму. Если провайдер сменит селектор темы, а манифест
не пересоберётся, переключение перестанет работать молча — и упадёт именно
эта проверка.

## Чего здесь намеренно нет

- **Слушателя `prefers-color-scheme`.** Системная схема читается один раз при
  создании контроллера. Подписка на её изменение — решение приложения:
  пользователь, выбравший тему руками, обычно не хочет, чтобы её перебила
  система.
- **Значений токенов в бандле.** Манифест по умолчанию несёт только имена и
  селекторы: значения уже в CSS, тащить их второй раз в JS незачем. Если они
  нужны самому приложению (превью палитры, canvas) — `includeTokens: true`.
