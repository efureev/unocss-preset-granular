# `apps/bench-pruned`

Тот же стенд, что `bench-one`, отличающийся **одной строкой конфига**:

```ts
pruneTokens: { mode: 'on', appSources: { dirs: [...] } }
```

Пара `bench-one` → `bench-pruned` и есть измерение эффекта обрезки. Всё
остальное в двух сборках обязано совпадать до байта, иначе разница перестаёт
быть разницей обрезки.

## Результат

```
роль           bench-one  bench-pruned         Δ   (gzip)
reset              1 065         1 065         0
pkg                1 585         1 585         0
app                  535           535         0
entry              1 478         1 481        +3
granular           1 936         1 156      −780
всего             29 855        29 078      −777
без vue            6 599         5 822      −777
```

Токены в дистрибутиве: **117 → 49 объявленных, мёртвый груз 68 → 0.**
Granular-слой похудел на 40 %, полная цена компонента (без `vue`) — на 12 %.

## Почему `appSources` обязателен

Пресет видит компоненты провайдера и **не видит разметку приложения**. Утилита
`bg-[var(--xh-accent)]`, написанная в `App.vue`, для него не существует, и без
`appSources` её токен уедет из CSS при зелёной сборке. В этом стенде разметка
без утилит, но строка стоит: стенд заодно документирует обязательный порядок
внедрения — `report` → посмотреть список → `on`.

## Что охраняет `expected-css.mjs`

Двенадцать проверок, и восемь из них — про случаи, где обрезка ломается молча:

| проверка | что было бы без неё |
|---|---|
| `--xh-z-dropdown` уцелел | имя собирается в рантайме из ОБЩЕГО модуля (`dist/internal/overlayZ.js`) — вне скана; ни один статический канал его не видит. Держит только `dynamicTokens` у `XhOverlay`. A/B: без объявления токен удаляется |
| `--xh-alert-duration` уцелел | читается из JS по имени, `var()` нет |
| `--xh-fg-boost` и `--xh-elevated-fg` уцелели | пара «объявлен только в светлой ↔ нужен только тёмной»; множество сохранённых, посчитанное потемно, её теряет |
| `--xh-invalid-brd` уцелел | роль ссылается на роль — замыкание обязано пройти по ссылке |
| `@supports not` на месте | фолбэк производной роли лежит внутри at-rule, которого плоский разбор блоков не видит |
| `box-sizing` на месте | `base.css` не обрезается: там правила сброса, а не объявления |

И четыре `absent` — что обрезка действительно убрала: сырая палитра, токены
невыбранного компонента, неиспользуемые ступени шкал.
