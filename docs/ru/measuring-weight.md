# Замер веса CSS/JS

> 🇬🇧 English version: [`../en/measuring-weight.md`](../en/measuring-weight.md).

Пресет обещает, что приложение платит только за выбранные компоненты. Этот
документ — про то, как это проверяется числами, а не на слово.

## Зачем

Фраза «компонент стоит N килобайт» бессмысленна без знаменателя. Поэтому в
репозитории три стенда, отличающихся ровно одним шагом каждый, и разница
между их дистрибутивами и есть искомая цена.

Отдельно измеряется то, что до сих пор никто не считал: сколько CSS-переменных
уезжает в дистрибутив и сколько из них реально потребляется.

## Три стенда

| стенд | что в нём | что меряет |
|---|---|---|
| `apps/bench-zero` | голый Vue, ни пресета, ни пакета | нулевая отметка |
| `apps/bench-one` | + пресет и один компонент | цена подключения |
| `apps/bench-pruned` | то же, плюс `pruneTokens.mode: 'on'` | эффект обрезки |

Обвязка сборки у всех трёх одинакова намеренно: иначе разница перестанет быть
разницей библиотеки.

## Раскладка ассетов

Чтобы приписать байты слою, слои разводятся по отдельным файлам. Чанки — через
группы кодсплиттинга:

```ts
build: {
  rolldownOptions: {
    output: {
      codeSplitting: {
        groups: [
          { name: 'reset', test: /node_modules[\\/]@unocss[\\/]reset[\\/]/, priority: 1 },
          { name: 'hpkg', test: (id) => id.startsWith(pkgDistDir), priority: 2 },
          { name: 'vue', test: /node_modules[\\/](?:vue|@vue)[\\/]/, priority: 3 },
        ],
      },
    },
  },
}
```

CSS — через три раздельных динамических импорта:

```ts
await Promise.all([
  import('./reset'), // '@unocss/reset/tailwind-compat.css' → reset-*.css
  import('./granular'), // 'virtual:uno:granular.css'          → granular-*.css
  import('./app'), // 'virtual:uno.css'                   → app-*.css
])
```

Получается шесть ролей: `vue`, `reset`, `granular` (фундамент и CSS
компонентов), `app` (утилиты), `pkg` (код компонентов), `entry`.

## Запуск

```bash
yarn build:all
yarn sizes         # отчёт: bench-one против bench-zero и bench-pruned против bench-one
yarn sizes:json    # то же машинно
yarn sizes:check   # строгая сверка с expected-budget.mjs каждого стенда
```

## Токены: объявлено против потребляется

Плоского подсчёта `var(` здесь мало. Производная роль ссылается на другую,
и токен, до которого дотягивается только значение мёртвого токена, тоже мёртв:

```css
:root {
  --soft: color-mix(in oklab, var(--danger) 18%, var(--bg));
}
```

Если `--soft` не потребляет никто, то `--danger` живым не становится. Поэтому
измеритель строит граф «токен → токены в его значении», берёт корнями только
потребления ВНЕ значений кастом-проперти и обходит граф. Отчёт печатает оба
числа и разницу отдельной строкой.

Второй канал — JS: имя токена часто лежит строкой, без `var(`.

```ts
const zVar = '--xh-z-dropdown'
const z = `var(${zVar})` // в исходниках `var(--xh-z-dropdown)` нет ни разу
el.style.setProperty('--xh-alert-bg', color)
```

Измеритель ищет и такие имена — в CSS, в JS-чанках и в разметке.

## Классы: доказательства использования

«Класс есть в CSS, но нет в JS» — не улика: `p-6` от пропа `padding="lg"`
физически не может встретиться строкой. Поэтому вердикты разведены:

| канал | доказательство? |
|---|---|
| целый токен в `class="…"` разметки | да |
| целый токен в строковом литерале JS | да |
| класс объявлен собственным CSS пакета | отдельная корзина |
| найден только литерал-префикс (`"p-"`) | нет, «вероятно» |
| ничего | не доказано |

Однозначен ровно один вердикт — **запись `safelist` не дала CSS вовсе**:
класс попросили, правила нет, селектора в дистрибутиве нет. Гейтится только он.

## JSON

```json
{
  "stand": "bench-pruned",
  "roles": { "granular": { "gzip": 1156, "delta": { "gzip": -780 } } },
  "tokens": { "declared": 49, "reachable": 49, "unused": [] },
  "safelist": { "dead": ["shadow-legacy"], "unproven": ["p-2", "p-3", "p-4"] }
}
```

## Чего замер не доказывает

- **Реальный вес у потребителя.** Меряется маргинальная цена ПЕРВОГО
  компонента: фундамент платится один раз.
- **Вес после сжатия на проде.** Параметры `zlib` здесь не равны настройкам CDN.
- **Что «недоказанный» класс лишний.** Доказать может только удаление записи
  и живая страница.
- **Что «неиспользуемый» токен лишний для пакета.** Вердикт всегда про ЭТО
  приложение с ЭТОЙ селекцией.
- **Корректность рендера.** Ни одной визуальной проверки: CSS, похудевший
  из-за того, что тема перестала инлайниться, выглядит в отчёте победой.

## Почему нет порога на байты

Порог по gzip невоспроизводим между средами: одно и то же дерево даёт разные
числа на macOS и на линуксовом раннере. А порог, взятый с потолка, начинает
краснеть на честном росте компонента, и его научаются поднимать не глядя.

Гейтятся поэтому только булевы факты: запись `safelist` не дала CSS; токен
потребляется без fallback и нигде не объявлен; ассет не опознан
классификатором. Байты — в вывод и в сводку прогона.
